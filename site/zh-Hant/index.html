你的 Bose SoundTouch 又能用了。

Bose 在 2026 年 5 月 6 日關閉了 SoundTouch 雲端。SoundTouch Manager 把網路電台、預設按鈕、Spotify 和遙控器帶回來。一切都在喇叭上運作，不需要帳號，也不需要雲端。

用 Android 應用程式安裝

手機和喇叭必須在同一個 Wi-Fi。在上架 Google Play 之前，請用這份檔案。喇叭設定裡可以把喇叭換到同一個家、訊號更強的另一個 Wi-Fi。不需要 Bose 的應用程式。

  1. 下載 SoundTouchManager-1.0.0-Android.apk. 如果瀏覽器說這個檔案可能傷害裝置，請選仍要下載。
  2. 允許安裝。 如果 Android 擋住，點設定，允許瀏覽器或檔案應用程式安裝不明的應用程式，然後再打開檔案。
  3. 通過 Play 保護機制。 如果顯示不明的應用程式，點更多詳細資料，再點仍要安裝。
  4. 打開應用程式，選擇「設定喇叭」。 它會把一個小代理程式複製到已經在你 Wi-Fi 上的喇叭。不需要 USB 隨身碟。

手機上的名稱是 SoundTouch Manager。支持會打開 GitHub Sponsors、PayPal 和 Ko-fi。沒有 iPhone 安裝包。Apple 只安裝它為那支手機簽過名的應用程式，或 App Store 裡的應用程式。

找回的功能

網路電台

在 radio-browser.info 搜尋成千上萬的電台，在任何一台喇叭上播放。

按鈕 1 到 6

喇叭和遙控器上的按鈕會再次播放你選的電台。

Spotify Connect

在喇叭上播放 Spotify，並把清單存成預設。

自己的音樂

瀏覽家中網路上的 DLNA 伺服器（FRITZ!Box、Synology、Plex、miniDLNA）。

多房間和立體聲

把喇叭放在一起同時播放，或組成左右一對。

手機遙控

每台喇叭都會在手機瀏覽器裡提供遙控。不需要商店，也不需要帳號。

更換 Wi-Fi

把已經裝了 SoundTouch Manager 的喇叭換到同一個家的另一個 Wi-Fi，然後把手機連到那個網路。

三個步驟

  1. 下載應用程式 Windows, macOS 或 Linux.
  2. 在和喇叭相同的網路上打開。 它會自己找到 SoundTouch。
  3. 選擇「設定喇叭」。 應用程式透過家中網路把一個小代理程式放進喇叭。不需要 USB 隨身碟；它只留作備用。
Windows 或 macOS 警告開發者不明

沒有程式碼簽章的版本，第一次打開時會出現警告。

  • Windows (SmartScreen): 更多資訊，然後按 仍要執行. 如果瀏覽器擋住 .exe，請下載這個 .zip.
  • macOS（Gatekeeper）： 磁碟映像是給 Apple Silicon（M1 或更新）用的。把應用程式拖到「應用程式」，按右鍵選打開，再選一次打開。或到系統設定、隱私權與安全性按仍要打開。
  • Linux: 解開壓縮檔，執行下面的指令，然後啟動。需要 GTK 3 和 WebKitGTK 4.1： chmod +x SoundTouchManager-1.0.0-Linux-x64.

要比對 SHA-256，確認下載完整，請對照 SHA256SUMS.

常見問題

需要 Bose 帳號或 Bose 的應用程式嗎？

不需要。一切都在喇叭和電腦上、在你家的網路裡運作。

可以更換喇叭的 Wi-Fi 嗎？

可以，前提是喇叭上已經有 SoundTouch Manager。打開喇叭設定，選擇更換喇叭的 Wi-Fi 網路。現在的網路和新的網路必須在同一個家：喇叭從它所在的位置加入新網路。然後把手機連到新網路。從來沒有上過網路的喇叭，要從設定喇叭開始，用 Bose 的應用程式、網路線或 USB 隨身碟設定。

喇叭需要哪個韌體？

SoundTouch Manager 是依照 Bose 最後釋出的韌體 27.0.6 製作並測試的。先更新喇叭，再安裝。做法寫在 docs/FIRMWARE-UPDATE.md（英文），使用的是 Bose 自己的映像檔和 USB 隨身碟。

韌體更新卡住或被拒絕

韌體舊很多的喇叭，有人回報無法直接跳到 27.0.6。實務上有效的做法是先降再升：先安裝 6.02.01，再安裝 27.0.6。更新前做原廠重設（按住 1 和音量降低十秒）有時能清掉設定到一半的狀態。這些步驟來自使用者回報，專案本身沒有重現；請看 docs/FIRMWARE-UPDATE.md第 4 節。

要怎麼從喇叭上移除？

在應用程式裡打開喇叭設定，選擇移除 STM。只做 Bose 原廠重設不會移除它。賣掉或送人之前請先做這一步。

有地方不能用

看看還沒解決的回報 GitHub. 儲存診斷紀錄.
