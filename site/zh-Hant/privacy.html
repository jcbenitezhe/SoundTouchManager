隱私說明

SoundTouch Manager。適用於 Google Play 的 Android 應用程式、桌面應用程式和這個網站。2026 年 10 月 5 日更新。

誰做的

SoundTouch Manager 是 Juan Carlos Benitez 的非官方應用程式。它與 Bose Corporation 無關，也沒有得到 Bose 的背書或授權。聯絡：jcbenitezhe@gmail.com。

沒有 SoundTouch Manager 帳號。沒有廣告，也沒有分析或當機回報服務。

留在家中網路的東西

應用程式在 Wi-Fi 上尋找 SoundTouch。名稱和區域網址留在手機和喇叭上，不會送給開發者。

它不詢問 GPS 位置。區域網路只用來找到並操作喇叭。

家中 DLNA 音樂庫的音樂留在那個網路上。應用程式不會上傳你的檔案。

你使用時應用程式會聯絡的服務

  • 網路電台。 搜尋電台會連到 radio-browser.info。那個服務看得到搜尋，以及搜尋裝置的網路位址。聲音之後從電台的伺服器、經由喇叭播放。
  • TuneIn。 瀏覽 TuneIn 會聯絡 TuneIn。TuneIn 是 TuneIn, Inc. 的商標。SoundTouch Manager 與 TuneIn 無關。
  • Spotify。 播放使用你自己的 Spotify 帳號。登入留在喇叭上。Spotify 收到的是一般的 Spotify Connect 工作階段。開發者拿不到你的 Spotify 密碼。
  • 電台圖示。 電台沒有圖示時，應用程式可能向 icons.duckduckgo.com 索取那個網站的公開圖示。請求裡有電台的網域，沒有你的名字。

喇叭不會聯絡 Bose 雲端。SoundTouch Manager 在你家的網路上回應那些請求。

Google Play 付款

Android 應用程式裡的自願支持是經由 Google Play 的一次性付款。付款由 Google 處理。開發者拿不到卡號。付款不會解鎖功能。應用程式仍然免費。

桌面應用程式裡的 PayPal、Ko-fi 和 GitHub Sponsors 連結會在瀏覽器打開那些網站。那些網站有自己的說明。在 Google Play 發行的 Android 應用程式用 Play 付款，不用那些連結。

你自己寄出的紀錄

應用程式不會自己送出紀錄。儲存診斷紀錄會在裝置上寫一份報告。匯出時會拿掉 IP 和裝置識別碼。除非你自己把檔案附在電子郵件或 GitHub issue 上，否則不會上傳。

這個網站

jcbenitezhe.github.io/SoundTouchManager 不放 cookie，也不做分析。網站放在 GitHub Pages。GitHub 可能記錄訪客的 IP。請看 GitHub 的政策。

兒童

SoundTouch Manager 不是給兒童用的。Google Play 的刊登對象是 18 歲以上。

資料保留多久

開發者沒有這個應用程式的帳號資料庫。喇叭設定在喇叭和你的裝置上。購買紀錄在你的 Google 帳號裡。網站紀錄如果有，由 GitHub 保管。
