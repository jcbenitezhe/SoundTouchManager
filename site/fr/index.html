Vos Bose SoundTouch, de nouveau en service.

Bose a éteint le cloud SoundTouch le 6 mai 2026. SoundTouch Manager rend la radio Internet, les touches de présélection, Spotify et la télécommande. Tout fonctionne sur votre enceinte, sans compte et sans cloud.

Installer avec l'application Android

Le téléphone et l'enceinte doivent être sur le même Wi-Fi. Utilisez cette copie jusqu'à ce que l'application soit sur Google Play. Dans les réglages de l'enceinte, vous pouvez la passer sur un autre Wi-Fi du même domicile, un réseau avec un meilleur signal. L'application Bose n'est pas nécessaire.

  1. Téléchargez SoundTouchManager-1.0.0-Android.apk. Si le navigateur dit que le fichier peut endommager l'appareil, choisissez Télécharger quand même.
  2. Autorisez l'installation. Si Android bloque, touchez Paramètres et autorisez le navigateur ou l'application Fichiers à installer des applications inconnues. Ouvrez ensuite le fichier à nouveau.
  3. Passez Play Protect. S'il indique que l'application est inconnue, touchez Plus de détails, puis Installer quand même.
  4. Ouvrez l'application et choisissez « Configurer une enceinte ». Elle copie un petit agent sur une enceinte déjà sur votre Wi-Fi. Aucune clé USB n'est nécessaire.

Sur le téléphone, l'application s'appelle SoundTouch Manager. Le soutien ouvre GitHub Sponsors, PayPal et Ko-fi. Il n'y a pas de paquet iPhone. Apple n'installe qu'une application qu'il a signée pour ce téléphone, ou une qui vient de l'App Store.

Ce qui revient

Radio Internet

Cherchez parmi des milliers de stations de radio-browser.info et écoutez-les sur n'importe quelle enceinte.

Touches 1 à 6

Les boutons de l'enceinte et de la télécommande fonctionnent de nouveau, avec les stations que vous choisissez.

Spotify Connect

Écoutez Spotify sur l'enceinte et enregistrez des listes sur les touches.

Votre musique

Parcourez les serveurs DLNA de votre réseau (FRITZ!Box, Synology, Plex, miniDLNA).

Multiroom et stéréo

Regroupez des enceintes pour qu'elles jouent ensemble, ou associez-en deux comme gauche et droite.

Télécommande sur le téléphone

Chaque enceinte offre une télécommande dans le navigateur du téléphone. Sans boutique ni compte.

Changer de Wi-Fi

Passez une enceinte qui a déjà SoundTouch Manager sur un autre Wi-Fi du même domicile. Reliez ensuite le téléphone à ce réseau.

Installation en trois étapes

  1. Téléchargez l'application pour Windows, macOS ou Linux.
  2. Ouvrez-la sur le même réseau que l'enceinte. Elle trouve vos enceintes SoundTouch toute seule.
  3. Choisissez « Configurer une enceinte ». L'application installe un petit agent sur l'enceinte par votre réseau domestique. Aucune clé USB n'est nécessaire ; elle reste possible en secours.
Windows ou macOS prévient que l'application vient d'un développeur inconnu

Une version sans signature de code affiche un avertissement à la première ouverture.

  • Windows (SmartScreen): cliquez sur Informations complémentaires, puis sur Exécuter quand même. Si le navigateur bloque le .exe, téléchargez le .zip et ouvrez le fichier qu'il contient.
  • macOS (Gatekeeper) : l'image est pour Apple Silicon (M1 ou plus récent). Glissez l'application dans Applications, cliquez droit, choisissez Ouvrir, puis Ouvrir encore. Ou allez dans Réglages Système, Confidentialité et sécurité et cliquez Ouvrir quand même.
  • Linux : décompressez, exécutez chmod +x SoundTouchManager-1.0.0-Linux-x64, puis lancez. Il faut GTK 3 et WebKitGTK 4.1.

Pour vérifier le téléchargement, comparez son SHA-256 avec SHA256SUMS.

Questions fréquentes

Faut-il un compte Bose ou l'application Bose ?

Non. Tout fonctionne sur votre enceinte et votre ordinateur, dans votre réseau domestique.

Puis-je changer le Wi-Fi de l'enceinte ?

Oui, quand SoundTouch Manager est déjà sur l'enceinte. Ouvrez les réglages et choisissez Configurer un autre Wi-Fi. Le réseau actuel et le nouveau doivent être dans le même domicile : l'enceinte rejoint le nouveau depuis l'endroit où elle se trouve. Reliez ensuite le téléphone au nouveau réseau. Une enceinte qui n'a jamais eu de réseau se configure depuis Configurer une enceinte, avec l'application Bose, un câble Ethernet ou une clé USB.

Quel micrologiciel faut-il ?

SoundTouch Manager est fait et testé avec le micrologiciel Bose 27.0.6, le dernier publié par Bose. Mettez d'abord l'enceinte à jour, puis installez. Le guide docs/FIRMWARE-UPDATE.md (en anglais) explique comment faire avec les images officielles de Bose et une clé USB.

La mise à jour du micrologiciel bloque ou est refusée

Des enceintes au micrologiciel très ancien ont refusé le saut direct vers 27.0.6. Ce qui a marché : descendre d'abord, puis monter, installer 6.02.01 puis 27.0.6. Une réinitialisation d'usine (maintenir 1 et volume moins dix secondes) avant la mise à jour peut effacer un état à moitié configuré. Ces étapes viennent de retours d'utilisateurs et le projet ne les a pas reproduites ; voir la section 4 du guide docs/FIRMWARE-UPDATE.md.

Comment le retirer d'une enceinte ?

Dans l'application, ouvrez les réglages de l'enceinte et choisissez Retirer STM. Une réinitialisation Bose seule ne le retire pas. Faites-le avant de vendre ou de donner une enceinte.

Quelque chose ne fonctionne pas

Consultez les problèmes ouverts sur GitHub. Enregistrer les journaux de diagnostic.
