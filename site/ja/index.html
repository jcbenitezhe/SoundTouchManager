あなたの Bose SoundTouch が、また動きます。

Bose は 2026年5月6日に SoundTouch のクラウドを停止しました。SoundTouch Manager はインターネットラジオ、プリセットボタン、Spotify、リモコンを戻します。すべてはスピーカーの中で動き、アカウントもクラウドも要りません。

Android アプリで導入する

電話とスピーカーは同じ Wi-Fi にいる必要があります。Google Play に出るまではこのコピーを使ってください。スピーカーの設定から、同じ家の中の、電波が強い別の Wi-Fi へ移せます。Bose のアプリは要りません。

  1. ダウンロード SoundTouchManager-1.0.0-Android.apk. ブラウザが端末に害があると出したら、このままダウンロードを選んでください。
  2. インストールを許可します。 Android が止めたら、設定を押し、ブラウザかファイルアプリに不明なアプリのインストールを許可します。そのあとファイルを開き直します。
  3. Play プロテクトを通します。 不明なアプリと出たら、詳細を押し、それからこのままインストールを押します。
  4. アプリを開き、「スピーカーをセットアップ」を選びます。 すでに Wi-Fi にあるスピーカーへ小さなエージェントをコピーします。USB メモリは要りません。

電話ではアプリ名は SoundTouch Manager です。支援は GitHub Sponsors、PayPal、Ko-fi を開きます。iPhone 用のパッケージはありません。Apple は、その電話向けに署名したアプリか、App Store のアプリしかインストールしません。

Wi-Fi を変える

すでに SoundTouch Manager があるスピーカーを、同じ家の別の Wi-Fi へ移します。そのあと電話をそのネットワークにつなぎます。

3つの手順

  1. アプリをダウンロード Windows, macOS または Linux.
  2. スピーカーと同じネットワークで開きます。 SoundTouch を自分で見つけます。
  3. 「スピーカーをセットアップ」を選びます。 アプリは家のネットワーク経由で、小さなエージェントをスピーカーに入れます。USB メモリは要りません。だめなときの予備として残しています。
Windows または macOS が、開発元が不明だと警告する

コード署名のないビルドは、最初に開くとき警告を出します。

  • Windows (SmartScreen): 詳細情報 をクリックし、次に 実行. ブラウザが .exe を止めたら、これをダウンロードします .zip.
  • macOS（Gatekeeper）： ディスクイメージは Apple Silicon（M1 以降）用です。アプリをアプリケーションにドラッグし、右クリックして 開く、もう一度 開く を選びます。または システム設定、プライバシーとセキュリティ で このまま開く を押します。
  • Linux: アーカイブを展開し、次を実行してから起動します。GTK 3 と WebKitGTK 4.1 が必要です： chmod +x SoundTouchManager-1.0.0-Linux-x64.

ダウンロードが壊れていないか、SHA-256 をこれと比べます SHA256SUMS.

よくある質問

Bose のアカウントや Bose のアプリは必要ですか？

いいえ。すべてはスピーカーとコンピュータの上、家のネットワークの中で動きます。

スピーカーの Wi-Fi を変えられますか？

はい。SoundTouch Manager がすでにスピーカーにあるときです。設定を開き、別のWi-Fiを設定を選びます。今のネットワークと新しいネットワークは同じ家になければいけません。スピーカーは今いる場所から新しいネットワークに入ります。そのあと電話を新しいネットワークにつなぎます。一度もネットワークに入ったことがないスピーカーは、スピーカーをセットアップから、Bose のアプリ、Ethernet ケーブル、または USB メモリで設定します。

スピーカーにどのファームウェアが必要ですか？

SoundTouch Manager は、Bose が最後に出したファームウェア 27.0.6 で作り、試しています。先にスピーカーを更新し、そのあと導入します。手順は docs/FIRMWARE-UPDATE.md（英語）にあり、Bose 自身のイメージと USB メモリを使います。

ファームウェアの更新が止まったり、拒否されたりする

ずっと古いファームウェアのスピーカーは、いきなり 27.0.6 へ飛ぶのを拒んだことがあります。うまくいったのは、一度下げてから上げることです。先に 6.02.01、そのあと 27.0.6。更新の前に初期化（1 と 音量ダウン を10秒押す）すると、途中まで設定された状態が消えることがあります。これは利用者の報告で、プロジェクトは再現していません。手順の第4節を見てください docs/FIRMWARE-UPDATE.md。

スピーカーから外すには？

アプリでスピーカーの設定を開き、STM を削除を選びます。Bose の初期化だけでは消えません。売る前、あげる前にやってください。

うまく動かない

未解決の報告を見てください GitHub. 診断ログを保存.
