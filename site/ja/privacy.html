プライバシー案内

SoundTouch Manager。Google Play の Android アプリ、デスクトップアプリ、このサイトについて。2026年10月5日更新。

だれが作っているか

SoundTouch Manager は Juan Carlos Benitez の非公式アプリです。Bose Corporation とは関係がなく、Bose の支持も許可も受けていません。連絡先: jcbenitezhe@gmail.com。

SoundTouch Manager のアカウントはありません。広告も、解析やクラッシュ報告のサービスもありません。

家のネットワークに残るもの

アプリは Wi-Fi 上の SoundTouch を探します。名前とローカルアドレスは電話とスピーカーに残ります。開発者には送られません。

GPS の位置は聞きません。ローカルネットワークは、スピーカーを見つけて操作するためだけに使います。

家の DLNA ライブラリの音楽は、そのネットワークに残ります。アプリはファイルをアップロードしません。

使うときにアプリが連絡するサービス

  • インターネットラジオ。 局の検索は radio-browser.info に行きます。そのサービスは検索と、検索した機器のネットワークアドレスを見ます。音声はそのあと局のサーバーから、スピーカーを通って流れます。
  • TuneIn。 TuneIn を見ると TuneIn に連絡します。TuneIn は TuneIn, Inc. の商標です。SoundTouch Manager は TuneIn と無関係です。
  • Spotify。 再生は自分の Spotify アカウントを使います。ログインはスピーカーに残ります。Spotify は普通の Spotify Connect のセッションを受け取ります。開発者は Spotify のパスワードを受け取りません。
  • 局のロゴ。 局にロゴがないとき、アプリは icons.duckduckgo.com にそのサイトの公開アイコンを頼むことがあります。その要求には局のドメインがあり、あなたの名前はありません。

スピーカーは Bose のクラウドに連絡しません。SoundTouch Manager が、家のネットワークの中でその要求に答えます。

Google Play の支払い

Android アプリの任意の支援は、Google Play を通した一回限りの支払いです。支払いは Google が処理します。開発者はカード番号を受け取りません。支払いで機能は開きません。アプリは無料のままです。

デスクトップアプリの PayPal、Ko-fi、GitHub Sponsors のリンクは、ブラウザでそのサイトを開きます。それらのサイトには独自の案内があります。Google Play で配る Android アプリは、それらのリンクの代わりに Play の支払いを使います。

自分で送るログ

アプリは自分からログを送りません。診断ログの保存は、機器の上に報告を書きます。その書き出しは IP アドレスと機器の識別子を除きます。自分でメールや GitHub の issue にファイルを付けない限り、アップロードされません。

このサイト

jcbenitezhe.github.io/SoundTouchManager はクッキーを置かず、解析もしません。GitHub Pages で公開しています。GitHub は訪問者の IP アドレスを記録することがあります。GitHub の方針を見てください。

子ども

SoundTouch Manager は子ども向けではありません。Google Play の掲載は 18 歳以上です。

データをどれだけ残すか

開発者はこのアプリのアカウントデータベースを持ちません。スピーカーの設定はスピーカーと機器にあります。購入の記録は Google アカウントにあります。サイトのログがあれば、それは GitHub が保管します。
